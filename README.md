#Project Overview
This project is meant to be a visualizer, tester and solver for the mora Jai puzzle boxes from the game Blue Prince.
These puzzles typically take place on a 3 by 3 grid and have an assortment of different colored tiles. Each colored tile has a different effect.
There are indicators in the corner that show you what the goal state of each corner of the grid should be.
Once you have matched all four corners you can open the box.

## Planned Features
- Variable board sizes (3x3, 5x5, 7x7 etc.)
- SQL database used for storing board layouts
- User configurable board layouts
- Solver to find the quickest solution, if posisble
  - This goal will be tricky there are still layouts that have been unsolved by the community
  - Initially my goal is to atleast have the program be able to solve the 8 initial puzzles in the game which take around 10 moves or less
